# 03. Tanimoto Similarity and Molecular Diversity

### 1. What It Is

The **Tanimoto similarity** (also called Tanimoto coefficient or Jaccard index for binary vectors) measures the overlap between two binary fingerprint bit-vectors:

$$T(A, B) = \frac{|A \cap B|}{|A \cup B|} = \frac{N_{AB}}{N_A + N_B - N_{AB}}$$

Where:
- N_AB: Number of bits set to 1 in both fingerprints
- N_A: Number of bits set to 1 in fingerprint A
- N_B: Number of bits set to 1 in fingerprint B

The result ranges from 0.0 (no shared bits) to 1.0 (identical fingerprints).

**Tanimoto distance** is 1 − T(A, B), ranging from 0 (identical) to 1 (completely different).

### 2. Why It Exists

Tanimoto similarity quantifies chemical similarity for three purposes in 3D-SynTree:

1. **Candidate retrieval:** Finding catalog synthons similar to a query fragment
2. **Diversity assessment:** Ensuring generated molecules cover diverse chemical space
3. **Mode collapse detection:** Preventing the model from repeatedly generating the same scaffold

### 3. How It Works

#### Similarity Calculation

Given two 2048-bit Morgan fingerprints:
1. Count bits set in both: N_AB
2. Count bits set in A: N_A
3. Count bits set in B: N_B
4. Compute: T = N_AB / (N_A + N_B − N_AB)

#### Interpretation Guidelines

| Tanimoto Range | Interpretation |
|----------------|----------------|
| 0.0 – 0.3 | Different scaffolds |
| 0.3 – 0.6 | Similar, some shared substructures |
| 0.6 – 0.85 | Very similar, likely same scaffold |
| 0.85 – 1.0 | Nearly identical, same core |

Molecules with T ≥ 0.85 generally share the same core chemical scaffold and tend to bind similar biological targets.

#### Diversity Reward

3D-SynTree computes batch diversity as:

$$R_{\text{div}}(\mathcal{M}_i) = \frac{1}{|\mathcal{B}| - 1} \sum_{j \ne i} \left(1 - T(\mathcal{M}_i, \mathcal{M}_j)\right)$$

This rewards molecules that are dissimilar from their batch siblings, encouraging exploration of diverse chemical space.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Shared bits (N_AB) | Bits set in both fingerprints |
| Bit counts (N_A, N_B) | Bits set in each fingerprint |
| Tanimoto coefficient | Similarity score (0–1) |
| Tanimoto distance | 1 − T, dissimilarity score |
| Threshold 0.85 | Same-scaffold cutoff |
| Batch diversity | Mean pairwise dissimilarity in a batch |
| Mode collapse | Model generating only one scaffold |

### 5. What You Must Understand

- **Tanimoto is not a distance metric in the strict mathematical sense.** It doesn't satisfy the triangle inequality. However, it works well for chemical similarity in practice.

- **Fingerprint size matters.** 1024-bit and 2048-bit fingerprints give different Tanimoto values for the same pair. Always use consistent fingerprint parameters when comparing.

- **T ≥ 0.85 is a heuristic, not a law.** Some molecules with T = 0.80 may have different binding profiles; some with T = 0.90 may bind differently due to a single critical atom.

- **Common pitfall:** Using raw bit counts instead of Tanimoto. Larger molecules set more bits, making raw counts biased toward larger molecules.

- **Common pitfall:** Assuming Tanimoto captures 3D similarity. Two molecules with identical fingerprints can have completely different 3D shapes.

### 7. Project Connection

The Tanimoto concepts map directly to the 3D-SynTree codebase:

- **`syntree/data/fragmenter.py`**: Uses Tanimoto ≥ 0.85 to identify candidate catalog synthons similar to query fragments.

- **`ThreeDReward.batch_diversity()`** in `syntree/engine/rl.py`: Computes batch diversity reward using pairwise Tanimoto distances.

- **Important caveat:** Batch diversity is a **non-stationary** metric—it depends on the other molecules in the batch. This violates the GFlowNet stationary reward contract (see [[09_MARKOV_DECISION_PROCESSES_AND_GFLOWNETS/05_Stationary Terminal Reward Formulation]]). Issue #30 [FLOW-02] addresses removing batch-relative metrics from the terminal reward.
