# 02. Morgan Circular Fingerprints

### 1. What It Is

**Morgan circular fingerprints** (also known as Extended-Connectivity Fingerprints, ECFP) are bit-vector representations of molecules. They encode local atomic environments by iteratively hashing atom neighborhoods at increasing radii, then folding the results into a fixed-length bit array.

The most common variant is **ECFP4** (radius = 2), folded into 2048 bits. Each bit represents the presence or absence of a particular substructural pattern in the molecule.

### 2. Why It Exists

Machine learning models cannot directly consume variable-sized molecular graphs. They need fixed-size numerical input. Fingerprints convert molecules into fixed-length vectors that can be fed into neural networks, used for similarity searching, or used for clustering.

Morgan fingerprints capture:
- **Local chemical environments:** Which atoms are near which other atoms
- **Substructure presence:** Whether specific patterns exist
- **Molecular similarity:** How similar two molecules are (via Tanimoto)

They do NOT capture:
- **3D geometry:** No x, y, z coordinates
- **Conformers:** No information about molecular shape
- **Spatial orientation:** No directional information

### 3. How It Works

#### Fingerprint Generation Algorithm

**Step 1: Initialize atom identifiers**
Assign each atom an initial integer based on:
- Element (atomic number)
- Degree (number of neighbors)
- Valence
- Charge
- Ring membership
- Hydrogen count

**Step 2: Iterative neighborhood hashing (R iterations)**
For each iteration:
- For each atom, collect identifiers of itself and all neighbors
- Hash this collection into a new identifier
- Replace old identifiers with new ones

After R iterations, each atom's identifier represents its R-neighborhood (all atoms within R bonds).

**Step 3: Collect all identifiers**
Gather all atom identifiers from all iterations.

**Step 4: Fold into fixed-length vector**
Hash each identifier modulo B (bit length, typically 2048):
$$\text{bit} = \text{hash}(\text{ID}) \pmod B$$
Set that bit to 1.

#### Example: Ethanol (CCO), Radius 1

Initial: C(methyl)-C(methylene)-O(hydroxyl)
Iteration 1: Each atom's ID incorporates its neighbors
- Methyl C: sees methylene C
- Methylene C: sees methyl C and O
- O: sees methylene C

Result: Three distinct neighborhood environments, folded into bits.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Radius (R) | Number of bond iterations (typically 2 for ECFP4) |
| Bit length (B) | Fixed vector size (typically 1024 or 2048) |
| Atom invariant | Initial feature vector per atom |
| Hashing function | Maps identifiers to bit positions |
| Folding | Modulo operation collapsing to fixed length |
| Bit collision | Different substructures mapping to same bit |
| ECFP4 | Morgan fingerprint with radius 2 |
| Binary fingerprint | Bit vector (0/1) vs count fingerprint |

### 5. What You Must Understand

- **Morgan fingerprints are lossy.** Hashing 2^32 possible identifiers into 2048 bits creates collisions—different substructures share bits. This is acceptable for similarity but not for exact reconstruction.

- **They capture 2D topology only.** Two molecules with identical connectivity but different 3D shapes (different conformers, stereoisomers) produce identical fingerprints.

- **Radius 2 (ECFP4) is standard.** It captures environments up to 2 bonds from each atom—sufficient for most functional groups and local chemistry.

- **Common pitfall:** Using fingerprints for 3D tasks. A fingerprint cannot distinguish between two conformers of the same molecule.

- **Common pitfall:** Comparing fingerprints of molecules with different sizes. A large molecule sets more bits than a small one, which can bias raw bit counts (Tanimoto similarity handles this by normalizing).
