# 05. Pharm3D 3D Pharmacophore Descriptors

### 1. What It Is

The **pharm3D descriptor** is a deterministic 2138-dimensional feature vector developed specifically for 3D-SynTree. It merges 2D chemical descriptors with explicit 3D conformer geometry, electrostatics, and attachment vectors into a single fixed-length representation.

Unlike Morgan fingerprints (which are 2D-only), pharm3D captures the 3D information needed for structure-based design: shape, electrostatics, and directional attachment vectors.

### 2. Why It Exists

2D fingerprints cannot answer questions like:
- Does this fragment physically fit the pocket cavity?
- Where are its reactive handles located in 3D space?
- What is its dipole moment and charge distribution?

pharm3D was designed to answer these questions deterministically on CPU, without heavy neural computation, providing the policy with 3D-aware synthon representations.

### 3. How It Works

The 2138-dimensional vector is a concatenation of six components:

| Component | Dimension | Description |
|-----------|-----------|-------------|
| Morgan fingerprint | 2048 | Unit-normalized ECFP4 fingerprint |
| 2D descriptors | 47 | Atom counts, Lipinski properties, functional groups |
| 3D shape descriptors | 6 | Radius of gyration, asphericity, eccentricity, NPR1, NPR2 |
| Electrostatic features | 5 | Gasteiger partial charge distribution, dipole magnitude |
| Directional vectors | 30 | Mean unit vectors from centroid to reactive handles |
| Magnitude scalar | 1 | Overall descriptor magnitude |

Total: 2048 + 47 + 6 + 5 + 30 + 1 = 2137 (rounded to 2138 with padding)

#### 3D Shape Descriptors

- **Radius of gyration:** RMS distance of atoms from molecular centroid
- **Asphericity:** Deviation from spherical shape
- **Eccentricity:** Measure of elongation
- **NPR1, NPR2:** Normalized principal moments of inertia (triangular shape space)

#### Electrostatic Features

- **Gasteiger partial charges:** Computed via `rdPartialCharges.ComputeGasteigerCharges()`
- **Dipole vector magnitude:** Overall molecular polarity

#### Directional Vectors

- **30 dimensions:** Mean unit vectors from molecular centroid to each of up to 10 reactive handles (3 dimensions each)
- Encodes where handles point in 3D space relative to molecular center

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| pharm3D | 2138-dimensional feature vector |
| Morgan fingerprint | 2048-bit ECFP4, unit-normalized |
| 2D descriptors | MW, logP, HBD, HBA, TPSA, rotatable bonds, ring counts |
| 3D shape | Radius of gyration, asphericity, eccentricity, NPR1, NPR2 |
| Electrostatics | Gasteiger charges, dipole moment |
| Directional vectors | Handle position vectors from centroid |
| Magnitude scalar | Overall vector magnitude |
| Deterministic | Same input always produces same output |
| CPU-computable | No GPU or neural network required |

### 5. What You Must Understand

- **pharm3D is deterministic, not learned.** Given a molecule and its 3D conformer, pharm3D always produces the same vector. Unlike neural network embeddings, it requires no training.

- **It bridges 2D and 3D.** The Morgan fingerprint captures 2D topology; the shape, electrostatic, and directional components capture 3D structure.

- **Directional vectors are the key innovation.** They tell the policy where reactive handles point in 3D, enabling it to select fragments whose handles align with pocket features.

- **Common pitfall:** Using pharm3D without a conformer. The 3D components require an embedded conformer; using a 2D-only structure makes them meaningless.

- **Common pitfall:** Normalization inconsistencies. The Morgan fingerprint is unit-normalized; other components are not. The projection (see [[06_CHEMINFORMATICS_AND_ALGORITHMS/04_Johnson Lindenstrauss and QR Projections]]) handles scale differences.

### 7. Project Connection

The pharm3D concepts map directly to the 3D-SynTree codebase:

- **`compute_pharm3d_descriptor()`** in `syntree/chemistry/synthon_encoder.py`: Computes the full 2138-dim pharm3D vector for a molecule.

- **`encode_catalog_pharm3d()`** in `syntree/chemistry/synthon_encoder.py`: Encodes all catalog synthons with pharm3D descriptors.

- **`syntree/chemistry/synthon_encoder.py`**: Main module for pharm3D computation and projection.

- **Cross-attention input** (`syntree/models/policy.py`): The synthon's pharm3D embedding (after projection to 256 dims) is used as input to the cross-attention mechanism.

### 8. Required Depth

**Essential.** pharm3D is the primary synthon representation in 3D-SynTree—understanding it is essential for understanding how the model selects fragments.
