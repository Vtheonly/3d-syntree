# 04. Johnson Lindenstrauss and QR Projections

### 1. What It Is

The **Johnson-Lindenstrauss (JL) lemma** is a mathematical theorem stating that a set of points in high-dimensional space can be projected into a much lower-dimensional space while approximately preserving all pairwise Euclidean distances.

The **QR projection** is a specific implementation using a random matrix whose columns are orthonormalized via QR decomposition (A = QR). When properly scaled, this projection preserves vector norms in expectation.

### 2. Why It Exists

The pharm3D descriptor in 3D-SynTree is 2138-dimensional. This high dimensionality creates problems:
- **Memory:** 2138-dim vectors × 50,000 synthons = large embedding tables
- **Computation:** Matrix multiplications with 2138-dim inputs are slow
- **Sparsity:** High-dimensional descriptors contain redundancy and noise
- **Curse of dimensionality:** Distance metrics become less meaningful in high dimensions

Projecting to 256 dimensions (an ~8.4× reduction) makes neural network operations fast and memory-efficient while approximately preserving the geometric relationships between descriptors.

### 3. How It Works

#### Random Projection

Generate a random matrix Q ∈ ℝ^(D×d) where D = 2138 (input dim) and d = 256 (output dim). Each entry is drawn from a Gaussian distribution.

#### Orthonormalization via QR Decomposition

The raw random matrix Q is not orthonormal. QR decomposition factorizes Q = QR where:
- Q (renamed): orthonormal columns (QᵀQ = I)
- R: upper triangular matrix

Using the orthonormal Q from QR decomposition ensures that the projection preserves norms and avoids axis shrinkage.

#### Scaling

When scaled by √(D/d), the projection preserves norms in expectation:

$$\mathbb{E}[\|\mathbf{x}Q\|_2^2] = \|\mathbf{x}\|_2^2$$

This scaling ensures that the expected squared length of the projected vector equals the original squared length.

#### Distance Preservation

The JL lemma guarantees that for any ε > 0, there exists a projection to O(log n / ε²) dimensions that preserves all pairwise distances within (1 ± ε). For 50,000 synthons with ε = 0.1, approximately 256 dimensions suffices.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| D | Original dimension (2138 for pharm3D) |
| d | Projected dimension (256 in 3D-SynTree) |
| Random Gaussian matrix | Initial random projection matrix |
| QR decomposition | Matrix factorization A = QR |
| Orthonormal basis | Columns with QᵀQ = I |
| Scaling factor | √(D/d) for norm preservation |
| JL lemma | Distance preservation guarantee |
| ε | Distortion tolerance |

### 5. What You Must Understand

- **QR orthonormalization matters.** A plain random Gaussian projection (without QR) suffers from axis shrinkage and subspace collapse—some dimensions get systematically compressed. QR ensures all dimensions are treated equally.

- **The projection is random but fixed.** Once generated, the projection matrix is fixed and applied to all descriptors. It is not learned during training.

- **Distances are approximately preserved, not exactly.** The JL lemma gives probabilistic guarantees with distortion ε. Small distance errors are acceptable for nearest-neighbor search and neural network input.

- **Common pitfall:** Using non-orthonormal random projections. The resulting embeddings have distorted geometry, which can bias downstream neural network learning.

- **Common pitfall:** Forgetting to scale. Without √(D/d) scaling, projected vectors are systematically shorter than originals.

### 6. Prerequisites

Linear algebra (matrix multiplication, QR decomposition, orthonormal bases, vector norms)

### 7. Project Connection

The JL and QR projection concepts map directly to the 3D-SynTree codebase:

- **`build_projection()`** in `syntree/chemistry/synthon_encoder.py`: Generates the orthonormal random projection matrix that converts 2138-dim pharm3D descriptors into 256-dim catalog embeddings.

- **Catalog embeddings:** The 256-dim projected vectors are stored in `enamine_real_50k_pharm3d_d256.h5` and used as synthon embeddings in the policy network.

- **`syntree/models/synthon_head.py`**: Uses these 256-dim embeddings for synthon selection via dot-product attention with the policy context.
