# 06. Cross-Attention Decoders for SBDD

### 1. What It Is

**Cross-attention** is a mechanism where a "query" attends over a "context" to selectively focus on relevant parts of the input. In structure-based drug design (SBDD), the query represents a decision (which atom to attach at, which synthon to select) and the context represents the protein-ligand environment processed by BipartitePaiNN.

Cross-attention allows the model to focus on specific pocket regions when making each decision, rather than treating the entire pocket uniformly.

### 2. Why It Exists

A binding pocket has 200–800 atoms, but only a few are relevant for any given attachment decision. Cross-attention lets the model:

- **Focus locally:** When deciding where to attach a carboxylic acid handle, attend to pocket residues with complementary chemistry (basic residues, H-bond donors)
- **Condition on context:** Synthon selection depends on the local pocket environment at the attachment site
- **Be interpretable:** Attention weights show which pocket atoms influenced each decision

### 3. How It Works

#### Cross-Attention Computation

**Step 1: Compute queries**
The attachment handle query q is derived from the core's exposed handle context (vector and scalar features).

**Step 2: Compute keys and values**
Pocket atom embeddings from BipartitePaiNN serve as keys K and values V:
- K_i = W_k · h_i (pocket atom i's embedding projected)
- V_i = W_v · h_i (value vector)

**Step 3: Compute attention scores**
$$score_i = \frac{q \cdot K_i}{\sqrt{d_k}}$$

**Step 4: Softmax normalization**
$$\alpha_i = \frac{\exp(score_i)}{\sum_j \exp(score_j)}$$

**Step 5: Weighted sum**
$$context = \sum_i \alpha_i V_i$$

The context vector is a weighted combination of pocket atom features, where weights reflect relevance to the query.

#### Multi-Head Cross-Attention

Multiple attention heads operate in parallel, each focusing on different aspects:
- Head 1: Electrostatic complementarity (charged residues)
- Head 2: Shape complementarity (hydrophobic pockets)
- Head 3: Hydrogen bonding potential (donor/acceptor pairs)

Outputs are concatenated and projected.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Query | Decision context (attachment handle, core embedding) |
| Key | Pocket atom embedding (what the pocket offers) |
| Value | Pocket atom embedding (what to extract) |
| Attention score | Relevance of pocket atom to query |
| Softmax | Normalizes scores to attention weights |
| Context vector | Weighted sum of pocket features |
| Multi-head | Multiple attention heads in parallel |
| Cross-attention | Query attends over external context (not self) |

### 5. What You Must Understand

- **Cross-attention is not self-attention.** In self-attention, queries, keys, and values all come from the same sequence. In cross-attention, queries come from one source (the decision context) and keys/values come from another (the pocket).

- **Attention weights are softmax-normalized.** They sum to 1 across all pocket atoms, forming a probability distribution over the pocket.

- **The context vector is SE(3)-invariant.** Even though pocket atom positions are equivariant, the attention-weighted sum produces a scalar context that doesn't change under rotation.

- **Common pitfall:** Using cross-attention without proper scaling. The 1/√d_k scaling prevents dot products from growing too large, which would push softmax into saturated regions.

- **Common pitfall:** Ignoring that attention is dynamic. The same pocket atom can have high attention for one decision and low attention for another, depending on the query.

### 7. Project Connection

The cross-attention concepts map directly to the 3D-SynTree codebase:

- **Cross-attention in `syntree/models/policy.py`**: Attachment handle queries attend over BipartitePaiNN pocket context to select attachment atoms.

- **Synthon head cross-attention** in `syntree/models/synthon_head.py`: Core context queries over catalog synthon embeddings to select compatible synthons.

- **Multi-head attention:** Different heads focus on different pocket features (electrostatics, shape, H-bonding).
