# 05. Equivariant Layers and PaiNN Readout Heads

### 1. What It Is

**Equivariant layers** are neural network layers whose outputs transform predictably under input transformations. In 3D-SynTree, PaiNN layers produce SE(3)-equivariant representations.

**Readout heads** are the final layers that convert node-level embeddings into task-specific predictions:
- **Attachment head:** Probability distribution over attachment atoms (scalar output per atom)
- **Synthon head:** Probability distribution over catalog synthons (scalar output per candidate)
- **Torsion head:** Continuous dihedral angle prediction (scalar output per torsion)

### 2. Why It Exists

After BipartitePaiNN message passing, each node has rich scalar and vector embeddings. But the downstream tasks require specific output types:

- **Attachment selection** needs per-atom probabilities (scalars)
- **Synthon selection** needs per-candidate probabilities (scalars)
- **Torsion prediction** needs continuous angles (scalars)

The readout heads must:
1. Extract the right information from node embeddings
2. Produce outputs of the correct type (scalar vs vector)
3. Maintain SE(3)-invariance for scalar predictions (probabilities shouldn't change under rotation)

### 3. How It Works

#### Attachment Head

For each pocket atom i, compute attachment probability:
1. Take pocket node embedding (scalar s_i and vector v_i)
2. Compute scalar attention score: α_i = MLP(s_i, ‖v_i‖)
3. Apply softmax over all pocket atoms: p_i = exp(α_i) / Σ_j exp(α_j)
4. Sample attachment atom i ~ Categorical(p)

The attachment probability is SE(3)-invariant because it depends only on scalars and vector magnitudes.

#### Synthon Head

For each catalog synthon candidate c:
1. Compute synthon embedding e_c (256-dim projected pharm3D)
2. Compute context vector from BipartitePaiNN output
3. Score: score_c = e_c · context (dot product)
4. Softmax over all candidates: p_c = exp(score_c) / Σ exp(score)

This is a dot-product attention mechanism where the context vector queries the synthon embedding table.

#### Torsion Head

For each rotatable bond:
1. Compute local environment embedding around the bond
2. Predict mean direction μ and concentration κ for a von Mises distribution
3. Sample dihedral angle θ ~ VonMises(μ, κ)

The von Mises distribution is the circular analogue of the Gaussian, appropriate for angular data.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Attachment head | Per-atom attachment probability |
| Synthon head | Per-candidate synthon probability |
| Torsion head | Continuous dihedral angle distribution |
| Softmax | Normalizes scores to probabilities |
| Dot-product attention | Context · embedding scoring |
| von Mises distribution | Circular distribution for angles |
| Scalar output | SE(3)-invariant prediction |
| Readout | Node embedding → task prediction |

### 5. What You Must Understand

- **Readout outputs must be invariant.** Probabilities and angles should not change when the protein-ligand complex is rotated. This is achieved by using only scalar features and vector magnitudes in the readout.

- **Dot-product attention is permutation-sensitive.** The synthon head scores each candidate independently against the context. The order of candidates in the catalog doesn't matter (each is scored independently), but the scores are relative to the current context.

- **Von Mises handles circularity.** Dihedral angles wrap at 360°. A Gaussian would treat 359° and 1° as far apart, but von Mises correctly treats them as close (circular distance = 2°).

- **Common pitfall:** Using vector features directly in scalar readout. Vector components change under rotation; only magnitudes (‖v‖) or dot products (v₁·v₂) are invariant.

- **Common pitfall:** Forgetting softmax temperature. The softmax temperature controls how peaked the distribution is—too low = deterministic (no exploration), too high = uniform (no learning).

### 7. Project Connection

The readout head concepts map directly to the 3D-SynTree codebase:

- **`AttachmentHead`** in `syntree/models/policy.py`: Per-atom attachment probability from pocket node embeddings.

- **`SynthonHead`** in `syntree/models/synthon_head.py`: Dot-product attention over catalog synthon embeddings.

- **`ContinuousTorsionHead`** in `syntree/models/torsion_head.py`: Von Mises distribution for dihedral angle prediction.

- **`syntree/models/policy.py`**: Combines attachment head, synthon head, and torsion head into the full policy network.
