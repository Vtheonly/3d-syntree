# 01. Stereochemistry Chirality and CIP Rules

### 1. What It Is

Stereochemistry is the study of the spatial arrangement of atoms in molecules and how that arrangement affects chemical behavior. Two molecules can have identical connectivity (the same atoms bonded in the same order) but different spatial arrangements—these are called **stereoisomers**.

A molecule is **chiral** if it cannot be superimposed on its mirror image. Your left and right hands are chiral: they are mirror images, but no matter how you rotate them, you cannot make them coincide. The same principle applies to molecules.

The **Cahn-Ingold-Prelog (CIP) priority rules** provide a systematic method for assigning absolute configuration to stereocenters. At an sp³ carbon with four different substituents, the CIP rules rank the substituents by atomic number, and the spatial arrangement determines whether the configuration is **R** (Rectus, clockwise) or **S** (Sinister, counter-clockwise).

### 2. Why It Exists

Stereochemistry exists because biological systems are chiral. Proteins, DNA, and cell membranes are all built from chiral building blocks (L-amino acids, D-sugars). A protein binding pocket is a chiral environment—it has a specific handedness.

This has profound consequences for drug discovery:

- **Enantiomers can have dramatically different biological activity.** The classic example is thalidomide: one enantiomer treats morning sickness, while the other causes severe birth defects. Both have identical connectivity and identical physical properties (boiling point, solubility, etc.), but only one fits the chiral biological target.

- **3D generation must maintain stereochemical integrity.** If 3D-SynTree generates an (R)-configured molecule but the conformer embedding flips it to (S), the resulting molecule may be completely inactive in the target pocket.

- **Amino acids in proteins are exclusively L-configured** (S at the α-carbon, except cysteine which is R due to sulfur's higher atomic number). This means protein pockets present chiral surfaces that discriminate between ligand enantiomers.

### 3. How It Works

#### Chiral Centers

An sp³ carbon with four different substituents is a **chiral center** or **stereocenter**. The four groups point toward the corners of a tetrahedron.

#### CIP Priority Assignment

1. **Rank by atomic number:** The atom directly attached to the stereocenter with the highest atomic number (Z) gets priority 1. The lowest gets priority 4.
2. **Tie-breaking:** If two substituents start with the same atom (e.g., both carbon), compare the atoms attached to each, moving outward until a difference is found.
3. **Multiple bonds:** A double bond to oxygen counts as two bonds to oxygen for CIP purposes. C=O is treated as C attached to (O, O, phantom).

#### R/S Assignment

With priority 4 pointing away from you:
- **Clockwise (1→2→3):** R configuration (Rectus)
- **Counter-clockwise (1→2→3):** S configuration (Sinister)

If priority 4 is pointing toward you, reverse the result.

### 4. What It Consists Of

| Concept | Description |
|---------|-------------|
| Stereoisomer | Same connectivity, different spatial arrangement |
| Chiral center | sp³ atom with four different substituents |
| Enantiomer | Non-superimposable mirror images |
| Diastereomer | Stereoisomers that are not mirror images |
| CIP rules | Priority ranking system (1→4) by atomic number |
| R configuration | Clockwise arrangement with priority 4 away |
| S configuration | Counter-clockwise arrangement with priority 4 away |
| Racemic mixture | 50:50 mixture of both enantiomers |
| Stereochemical retention | Configuration preserved during reaction |
| Stereochemical inversion | Configuration flipped during reaction |

### 5. What You Must Understand

- **Enantiomers have identical physical properties but different biological activity.** Melting point, boiling point, and solubility are the same for both enantiomers. Only in a chiral environment (like a protein pocket) do they differ.

- **The biological target is chiral.** A protein pocket is built from L-amino acids. It can distinguish between (R) and (S) ligands because only one fits the chiral arrangement of binding residues.

- **3D embedding can destroy stereochemistry.** RDKit's ETKDG and force-field minimization can invert stereocenters if not constrained. 3D-SynTree uses `Chem.AssignStereochemistry(cleanIt=True, force=True)` and `enforceChirality=True` to prevent this.

- **Common pitfall:** Students often treat stereochemistry as a label that can be added after the fact. In reality, stereochemistry is determined at bond formation and must be tracked through every reaction step.

- **Common pitfall:** CIP priorities depend on atomic number, not on chemical importance. A chlorine (Z=17) always outranks oxygen (Z=8), even if oxygen is more chemically relevant to the reaction.

### 7. Project Connection

The stereochemistry concepts map directly to the 3D-SynTree codebase:

- **`Chem.AssignStereochemistry(cleanIt=True, force=True)`** in `ConformerEngine.embed_product()` (`syntree/chemistry/conformer.py`): Reassigns stereochemistry after reaction execution, ensuring chiral centers are correctly identified.

- **`enforceChirality=True`** in `ConformerEngine.embed_product()`: Forces RDKit's embedding algorithm to preserve specified chirality during 3D coordinate generation.
