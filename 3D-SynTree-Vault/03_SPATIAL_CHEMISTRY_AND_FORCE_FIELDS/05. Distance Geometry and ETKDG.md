# 05. Distance Geometry and ETKDG

### 1. What It Is

**Distance geometry** is the mathematical problem of determining 3D coordinates for a set of points given only pairwise distance constraints. In molecular modeling, this means converting a 2D molecular graph (which encodes which atoms are bonded, but not their 3D positions) into a physically realistic 3D conformer.

**ETKDG** (Experimental Torsion Knowledge Distance Geometry) is a specific algorithm developed by Riniker and Landrum that improves distance geometry by incorporating empirical torsion angle preferences from the Cambridge Structural Database (CSD). It is the standard method in RDKit for generating 3D conformers from 2D molecular structures.

### 2. Why It Exists

2D molecular graphs encode connectivity (which atom is bonded to which) but contain no 3D spatial information. To evaluate how a molecule fits into a protein binding pocket, we need 3D coordinates. Distance geometry provides the bridge:

1. Start with a 2D graph
2. Derive distance bounds from bond lengths, angles, and chemical knowledge
3. Embed atoms in 3D space satisfying those bounds
4. Refine the geometry to minimize constraint violations

ETKDG exists because pure distance geometry often produces unrealistic conformers—rings in impossible conformations, incorrect stereochemistry, or torsion angles never observed in real molecules. By incorporating experimental torsion preferences, ETKDG generates conformers that match what crystallographers actually observe.

### 3. How It Works

#### ETKDG Pipeline

**Step 1: Distance Bound Calculation**
- Compute upper and lower bounds for all atom pairs from covalent bond lengths, bond angles, and chemical rules
- Apply triangle inequality smoothing: if d(A,B) ≤ 5 and d(B,C) ≤ 5, then d(A,C) ≤ 10

**Step 2: Metric Matrix Embedding**
- Construct a distance matrix from the bounds
- Perform eigenvalue decomposition to embed atoms in 4D space
- Project to 3D using the largest eigenvalues

**Step 3: Torsion Angle Refinement**
- Apply empirical torsion angle preferences from the CSD
- For each rotatable bond, bias toward observed rotamer basins (gauche, anti)
- This is the "Experimental Torsion Knowledge" component

**Step 4: Conjugate Gradient Minimization**
- Minimize distance constraint violations using conjugate gradient methods
- Refine coordinates to satisfy all bounds as closely as possible

**Step 5: Stereochemistry Enforcement**
- Apply chirality constraints from the 2D graph's stereochemical annotations
- Ensure R/S configurations are preserved

#### CoordMap Constraints

In 3D-SynTree, ETKDG is used with `coordMap` constraints to anchor the existing scaffold in pocket coordinates while embedding only the new synthon atoms. The coordMap specifies fixed positions for core atoms, preventing them from drifting during embedding.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Distance geometry | Determining coordinates from pairwise distances |
| Distance bounds | Upper and lower limits for atom-atom distances |
| Triangle inequality | Smoothing constraint: d(A,C) ≤ d(A,B) + d(B,C) |
| Metric matrix | Matrix of squared distances used for embedding |
| Eigenvalue decomposition | Mathematical method for coordinate extraction |
| CSD | Cambridge Structural Database, source of torsion preferences |
| Torsion library | Empirical preferred angles for rotatable bonds |
| Conjugate gradient | Optimization algorithm for constraint satisfaction |
| CoordMap | Fixed-coordinate constraints for scaffold anchoring |

### 5. What You Must Understand

- **ETKDG embeds internal geometry, not absolute position.** The algorithm generates a conformer in an arbitrary coordinate frame. The scaffold must be aligned to the pocket afterward using Kabsch alignment (see [[03_SPATIAL_CHEMISTRY_AND_FORCE_FIELDS/07_The Kabsch Algorithm and Rigid Alignment]]).

- **Torsion preferences come from real data.** The CSD contains hundreds of thousands of experimentally determined crystal structures. ETKDG uses this data to bias rotatable bonds toward observed conformations rather than random ones.

- **Distance geometry can fail.** If bounds are inconsistent (e.g., three atoms with d(A,B)=1, d(B,C)=1, d(A,C)=5), no embedding exists. ETKDG includes smoothing to handle minor inconsistencies.

- **Common pitfall:** Expecting ETKDG to produce a unique conformer. Distance geometry is stochastic—different random seeds produce different conformers. Multiple embeddings are usually generated and the best one selected.

- **Common pitfall:** Forgetting that ETKDG respects the 2D graph's stereochemistry. If the input SMILES specifies (R) at a center, ETKDG will attempt to preserve it.

### 7. Project Connection

The ETKDG concepts map directly to the 3D-SynTree codebase:

- **`AllChem.ETKDGv3()`** in `ConformerEngine.embed_product()` (`syntree/chemistry/conformer.py`): RDKit's ETKDG implementation with coordMap constraints for scaffold anchoring.

- **`coordMap` constraints**: Dictionary mapping atom indices to fixed 3D positions, used to keep the core scaffold locked in the pocket frame while embedding the new synthon.

- **`ConformerEngine.embed_product()`** in `syntree/chemistry/conformer.py`: Full pipeline for embedding a reacted product—ETKDG for internal geometry, Kabsch for alignment, dihedral application for torsion.
