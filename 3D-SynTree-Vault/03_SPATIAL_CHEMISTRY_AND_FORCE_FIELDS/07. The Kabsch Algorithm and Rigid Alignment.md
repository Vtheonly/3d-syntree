# 07. The Kabsch Algorithm and Rigid Alignment

### 1. What It Is

The **Kabsch algorithm** is a mathematical method for computing the optimal rigid-body transformation (rotation matrix R and translation vector t) that aligns one set of 3D points onto another, minimizing the root-mean-square deviation (RMSD) between them.

A rigid-body transformation preserves all internal distances and angles—it only rotates and translates the entire object as a unit. This is essential for molecular modeling because the internal geometry of a molecule (bond lengths, angles) must remain unchanged when moving it into a new coordinate frame.

### 2. Why It Exists

ETKDG embeds a newly reacted product in an arbitrary coordinate frame. The core scaffold atoms must be aligned back onto the protein's coordinate frame without distorting the core's internal geometry. Without Kabsch alignment:

- The core would float away from the protein pocket
- The newly attached synthon would be in the wrong position relative to the pocket
- The junction dihedral would be measured in the wrong frame

The Kabsch algorithm guarantees optimal alignment via singular value decomposition (SVD), with a correction to ensure proper right-handed rotation (no reflections).

### 3. How It Works

#### Kabsch Algorithm Steps

Given two paired point sets P (reference, e.g., protein pocket) and Q (mobile, e.g., embedded product):

**Step 1: Center both matrices**
Compute centroids: μ_P = mean(P), μ_Q = mean(Q)
Center: P₀ = P − μ_P, Q₀ = Q − μ_Q

**Step 2: Compute cross-covariance matrix**
H = P₀ᵀ Q₀ (a 3×3 matrix)

**Step 3: Singular Value Decomposition**
H = U Σ Vᵀ

**Step 4: Ensure proper rotation (det(R) = +1)**
Compute d = sign(det(V Uᵀ))
R = V [[1, 0, 0], [0, 1, 0], [0, 0, d]] Uᵀ

The d term corrects for reflections, ensuring the rotation is right-handed (det(R) = +1).

**Step 5: Compute translation**
t = μ_Q − R μ_P

**Step 6: Apply transformation**
P_aligned = R P + t

#### RMSD

The root-mean-square deviation quantifies alignment quality:

$$\text{RMSD} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} \|p_i - q_i\|^2}$$

Kabsch minimizes this value over all possible rotations and translations.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Rotation matrix R | 3×3 orthogonal matrix with det(R) = +1 |
| Translation vector t | 3D vector shifting the object's center |
| Centroid | Mean position of a point set |
| Cross-covariance matrix H | Captures correlation between point sets |
| SVD | Singular value decomposition, matrix factorization |
| Reflection correction | d term ensuring right-handed rotation |
| RMSD | Root-mean-square deviation, alignment quality metric |
| Rigid-body transformation | Rotation + translation, preserving internal geometry |

### 5. What You Must Understand

- **Kabsch preserves internal geometry.** All bond lengths, angles, and dihedrals within the mobile set remain unchanged. Only the position and orientation change.

- **The reflection correction is critical.** Without the d term, SVD can produce a reflection (det(R) = −1), which would invert the molecule's chirality—turning an (R)-center into (S).

- **Paired points are required.** Kabsch needs known correspondences between points in P and Q. In 3D-SynTree, these come from the isotope provenance mapping (core atoms matched to their pocket positions).

- **Common pitfall:** Using Kabsch on unpaired point sets. The algorithm requires knowing which atom in P corresponds to which atom in Q.

- **Common pitfall:** Forgetting that Kabsch finds the global optimum. It is not iterative—it computes the exact best alignment in one step.

### 7. Project Connection

The Kabsch algorithm maps directly to the 3D-SynTree codebase:

- **`_kabsch()`** in `syntree/chemistry/conformer.py`: Implements the full Kabsch algorithm—centering, cross-covariance, SVD, reflection correction, and translation—to realign newly embedded products onto the locked scaffold reference frame.

- **Isotope provenance** (`syntree/chemistry/reactions.py`): Provides the atom correspondence mapping (`core_atom_map`) that tells Kabsch which product atoms correspond to which pocket positions.

- **`ConformerEngine.embed_product()`** in `syntree/chemistry/conformer.py`: Calls Kabsch after ETKDG embedding to position the product correctly in the pocket frame.
