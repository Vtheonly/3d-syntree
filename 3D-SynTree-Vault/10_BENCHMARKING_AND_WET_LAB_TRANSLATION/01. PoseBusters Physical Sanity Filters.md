# 01. PoseBusters Physical Sanity Filters

### 1. What It Is

**PoseBusters** is a set of physical validity checks for generated molecular poses (3D structures). It verifies that a molecule's geometry is physically reasonable before accepting it as a valid output.

PoseBusters checks include:
- Bond lengths within acceptable ranges
- Bond angles within acceptable ranges
- No steric clashes (atoms too close)
- Proper stereochemistry
- Valid valences
- Reasonable torsion angles

### 2. Why It Exists

Generative models can produce molecules that look good by scoring metrics but are physically impossible:

- Bonds stretched to 3.0 Å (normal is ~1.5 Å)
- Atoms occupying the same space (steric clash)
- Impossible bond angles (e.g., 10° instead of 109.5°)
- Stereochemistry violations

Without PoseBusters filtering, the model might generate "molecules" that cannot exist in reality, wasting experimental validation resources.

### 3. How It Works

#### Bond Length Checks

| Bond Type | Typical Length (Å) | Tolerance |
|-----------|-------------------|-----------|
| C-C single | 1.54 | ±0.15 Å |
| C=C double | 1.34 | ±0.10 Å |
| C≡C triple | 1.20 | ±0.08 Å |
| C-N | 1.47 | ±0.15 Å |
| C-O | 1.43 | ±0.15 Å |

#### Bond Angle Checks

| Angle Type | Typical (°) | Tolerance |
|------------|-------------|-----------|
| sp³ (tetrahedral) | 109.5 | ±15° |
| sp² (trigonal) | 120 | ±15° |
| sp (linear) | 180 | ±15° |

#### Steric Clash Check

Two non-bonded atoms are in clash if their distance is less than the sum of their van der Waals radii minus a tolerance (typically 0.5 Å).

#### Stereochemistry Check

Chiral centers must have correct R/S configuration as specified. Double bonds must have correct E/Z geometry.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Bond length check | Covalent bond lengths within tolerance |
| Bond angle check | Angles within acceptable range |
| Steric clash check | Non-bonded atoms not too close |
| Stereochemistry check | Correct R/S and E/Z configuration |
| Valence check | Atoms don't exceed maximum valence |
| Torsion check | Reasonable dihedral angles |
| Pass/fail | Binary validity decision |

### 5. What You Must Understand

- **PoseBusters is a filter, not a corrector.** It rejects invalid molecules; it doesn't fix them. MMFF94 minimization (see [[03_SPATIAL_CHEMISTRY_AND_FORCE_FIELDS/06_Molecular Mechanics and MMFF94 Restraints]]) is the correction step.

- **Tolerances matter.** Too tight = too many false rejections. Too loose = physically invalid molecules pass through.

- **PoseBusters checks are applied after generation.** The model generates a molecule, MMFF94 relaxes it, then PoseBusters validates it.

- **Common pitfall:** Skipping PoseBusters and trusting docking scores. A molecule can dock well but have impossible geometry.

- **Common pitfall:** Using PoseBusters as the only quality metric. It checks physical validity, not binding affinity or drug-likeness.

### 7. Project Connection

The PoseBusters concepts map directly to the 3D-SynTree codebase:

- **`PoseBusters`** in `syntree/chemistry/validator.py`: Physical validity checks for generated poses.

- **`validate_pose()`** in `validator.py`: Runs all PoseBusters checks and returns pass/fail.

- **`syntree/chemistry/validator.py`**: Main validation module with bond length, angle, clash, and stereochemistry checks.

- **PoseBusters is applied** after MMFF94 relaxation in the trajectory generation pipeline (`scripts/build_trajectories.py`).

### 8. Required Depth

**Essential.** PoseBusters is the gatekeeper that prevents physically invalid molecules from reaching experimental validation.
