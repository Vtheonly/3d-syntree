# 03. Baseline Comparisons TargetDiff SyntheMol

### 1. What It Is

3D-SynTree is compared against several baseline methods in structure-based and ligand-based drug design:

**Structure-based generative models (3D-aware):**
- **TargetDiff:** Diffusion model generating atoms and bonds in the binding pocket
- **DiffSBDD:** Denoising diffusion for structure-based drug design
- **Pocket2Mol:** Graph generation conditioned on pocket graph

**Ligand-based / 2D generative models:**
- **SyntheMol:** Template-based synthesis with retrosynthetic filtering
- **SynNet:** Retrosynthesis-guided generative model

### 2. Why It Exists

Baseline comparisons answer the question: "Is 3D-SynTree better than existing methods?" Without comparisons, we can't tell if our improvements are real or just random variation.

Different baselines test different hypotheses:
- **vs TargetDiff/DiffSBDD:** Is GFlowNet sequential synthesis better than diffusion for structure-based design?
- **vs Pocket2Mol:** Is explicit pocket conditioning better than graph generation?
- **vs SyntheMol/SynNet:** Is 3D-aware generation better than 2D/retrosynthesis-based approaches?

### 3. How It Works

#### Comparative Benchmark Protocol

1. **Select test targets:** 100 protein targets clustered at < 30% sequence identity (held out from training)

2. **Generate molecules:** Each method generates N molecules per target

3. **Evaluate:** Compute docking scores, success rates, novelty, diversity, QED, Fsp3

4. **Compare:** Rank methods by each metric

#### Evaluation Pipeline

| Step | Description |
|------|-------------|
| Target selection | 100 held-out targets |
| Molecule generation | N molecules per target per method |
| PoseBusters filtering | Remove physically invalid molecules |
| Docking | Dock into pocket, record score |
| Metric computation | Success rate, novelty, diversity, QED, Fsp3 |
| Statistical testing | Significance of differences |

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| TargetDiff | Diffusion-based structure-based generative model |
| DiffSBDD | Denoising diffusion for SBDD |
| Pocket2Mol | Pocket-conditioned graph generation |
| SyntheMol | Template-based synthesis with retrosynthesis |
| SynNet | Retrosynthesis-guided generative model |
| Held-out targets | 100 targets at < 30% sequence identity |
| Docking score | Vina/GNINA binding affinity proxy |
| Success rate | Valid, bindable fraction |
| Novelty | Not in training set fraction |
| Diversity | Scaffold diversity |

### 5. What You Must Understand

- **Baselines must be evaluated identically.** Same targets, same number of generated molecules, same filtering (PoseBusters), same docking protocol. Otherwise comparisons are meaningless.

- **3D-SynTree's advantages:** GFlowNet sampling proportional to reward, explicit 3D geometry with MMFF94 + Kabsch, certified reaction grammar, Fsp³ constraint.

- **Baseline strengths:** Diffusion models (TargetDiff) excel at exploring continuous 3D space; template methods (SyntheMol) guarantee synthesizability.

- **Common pitfall:** Comparing methods on different test sets. Results are not comparable across different targets.

- **Common pitfall:** Not reporting variance. Single runs can be lucky/unlucky; report mean ± std over multiple seeds.

### 7. Project Connection

The baseline comparison concepts map directly to the 3D-SynTree codebase:

- **`scripts/run_comparative_benchmark.py`**: Main benchmark script comparing 3D-SynTree against TargetDiff, DiffSBDD, Pocket2Mol, SyntheMol, SynNet.

- **`syntree/engine/evaluator.py`**: Computes all evaluation metrics for comparison.

- **`unified_splits_30seq_id.parquet`**: Held-out test targets at < 30% sequence identity.

- **`syntree/chemistry/validator.py`**: PoseBusters filtering applied to all methods equally.
