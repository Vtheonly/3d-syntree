# 02. Evaluation Metrics and Success Criteria

### 1. What It Is

Evaluation metrics quantify how well 3D-SynTree generates molecules that bind to target proteins. Success criteria define what constitutes a successful design campaign.

| Metric | What It Measures | Good Value |
|--------|-----------------|------------|
| Vina docking score | Predicted binding affinity | < -10 kcal/mol |
| Success rate | Fraction of valid, bindable molecules | > 60% |
| Novelty | Fraction of molecules not in training set | > 90% |
| Diversity | Scaffold diversity of generated set | High |
| PoseBusters pass rate | Fraction passing physical sanity checks | > 90% |
| QED | Drug-likeness score | > 0.5 |
| Fsp3 | 3D character (sp³ fraction) | > 0.40 |
| Hit rate | Fraction with experimental activity | Target-dependent |

### 2. Why It Exists

Without standardized metrics, you cannot compare:
- Different model versions (v0.1 vs v0.2)
- Different methods (3D-SynTree vs TargetDiff vs DiffSBDD)
- Different targets (kinase vs protease vs GPCR)

Metrics provide objective, reproducible evidence that the method works.

### 3. How It Works

#### Docking Score Evaluation

Generated molecules are docked into the binding pocket using Vina or GNINA. The docking score (kcal/mol) is a proxy for binding affinity. Lower (more negative) = better predicted binding.

#### Success Rate

The fraction of generated molecules that:
1. Pass PoseBusters physical sanity checks
2. Have a valid docking score
3. Meet minimum QED and Fsp3 thresholds

#### Novelty

Generated molecules are compared to the training set using Tanimoto similarity (Morgan fingerprints, T ≥ 0.85 = same scaffold). Novelty = fraction with T < 0.85 to all training molecules.

#### Diversity

Measured as the average pairwise Tanimoto distance within a generated set. Higher distance = more diverse.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Vina docking score | Predicted binding affinity (kcal/mol) |
| Success rate | Fraction of valid, bindable molecules |
| Novelty | Fraction not in training set |
| Diversity | Scaffold diversity within generated set |
| PoseBusters pass rate | Physical validity rate |
| QED | Drug-likeness score |
| Fsp3 | sp³ fraction (3D character) |
| Hit rate | Experimental validation rate |

### 5. What You Must Understand

- **Docking scores are approximate.** Vina scores correlate with affinity but don't predict exact K_D. They're useful for ranking but not absolute values.

- **Success rate > binding score.** A molecule with excellent docking but impossible geometry (PoseBusters failure) is worthless. Physical validity comes first.

- **Novelty prevents memorization.** If the model just regenerates training molecules, it's not learning to design—it's memorizing.

- **Common pitfall:** Optimizing docking score alone. This produces flat, lipophilic molecules that score well but are undevelopable.

- **Common pitfall:** Reporting success rate without PoseBusters. Invalid molecules inflate success rates artificially.

### 7. Project Connection

The evaluation metrics map directly to the 3D-SynTree codebase:

- **`scripts/run_comparative_benchmark.py`**: Runs 3D-SynTree against baselines (TargetDiff, DiffSBDD, Pocket2Mol, SyntheMol, SynNet).

- **`syntree/engine/evaluator.py`**: Computes docking scores, success rates, novelty, and diversity.

- **`syntree/data/curation.py`**: Stores PDBbind affinity values for comparison.

- **`100-target test manifest`**: Held-out targets clustered at < 30% sequence identity for unbiased benchmarking.

### 8. Required Depth

**Essential.** Evaluation metrics determine whether 3D-SynTree actually works.
