# 05. X-Ray Crystallography and PDB Artifacts

### 1. What It Is

**X-ray crystallography** is the primary experimental method for determining atomic-resolution 3D protein structures. X-rays diffract off electrons in a protein crystal, producing a diffraction pattern from which an electron density map is calculated. Atomic coordinates are fitted into this density.

The **Protein Data Bank (PDB)** is the global repository for these structures. However, PDB files are not pristine biological representations—they contain experimental artifacts, crystallization additives, missing regions, and modeling errors that must be understood and filtered.

### 2. Why It Exists

3D-SynTree requires 3D protein coordinates as input. These come almost exclusively from X-ray crystallography (with some from Cryo-EM and NMR). Understanding how these structures are generated—and what errors they contain—is essential for:

- **Data curation:** Filtering out low-quality or artifact-contaminated structures
- **Interpretation:** Knowing which features are real and which are experimental noise
- **Model training:** Ensuring the neural network learns from physically realistic structures

### 3. How It Works

#### X-Ray Crystallography Pipeline

1. **Protein purification and crystallization:** Protein is concentrated and induced to form an ordered crystal lattice

2. **X-ray diffraction:** X-rays strike the crystal, diffracting off electron clouds to produce a diffraction pattern

3. **Electron density map:** Fourier transform of diffraction data produces 3D electron density (Fₒ map)

4. **Model building:** Atomic coordinates are fitted into density, iteratively refined against observed data

5. **PDB deposition:** Final coordinates and metadata deposited to PDB

#### Data Quality Metrics

| Metric | Description | Good Quality |
|--------|-------------|--------------|
| Resolution | Minimum resolvable distance (Å) | ≤ 2.5 Å (high), ≤ 1.5 Å (excellent) |
| B-factor | Atomic displacement/uncertainty | Low = well-ordered, High = disordered |
| R-factor | Agreement between model and data | Low = good fit |
| RSCC | Real-space correlation coefficient | High = good local fit |

#### Common PDB Artifacts

| Artifact | Description | Action |
|----------|-------------|--------|
| GOL | Glycerol (cryoprotectant) | Remove |
| PEG | Polyethylene glycol (precipitant) | Remove |
| EDO | Ethylene glycol (cryoprotectant) | Remove |
| DMSO | Dimethyl sulfoxide (solvent) | Remove |
| SO₄²⁻ | Sulfate (crystallization salt) | Remove |
| Alternative conformations | Multiple modeled positions | Select primary or model all |
| Missing loops | Disordered regions with no coordinates | Handle or exclude |

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Electron density map | 3D map of electron density from diffraction |
| Resolution (Å) | Minimum detail resolvable in structure |
| B-factor | Thermal motion/positional uncertainty |
| ARTIFACT_RESNAMES | Set of non-biological residues to filter |
| Fₒ − F_c | Difference density (observed minus calculated) |
| HETATM | PDB record for non-standard residues |
| ATOM | PDB record for standard amino acid atoms |
| Occupancy | Fraction of molecules with atom at this position |

### 5. What You Must Understand

- **PDB files are experimental models, not truth.** Each coordinate has uncertainty (B-factor). At 2.5 Å resolution, side-chain positions are approximate; hydrogen positions are almost never directly observed.

- **Resolution matters.** At 1.5 Å, you can see individual atoms and water molecules clearly. At 3.0 Å, the backbone is traceable but side chains are ambiguous. 3D-SynTree filters for resolution ≤ 2.5 Å.

- **Crystallization additives are not biology.** Glycerol, PEG, sulfate ions, and other crystallization components appear in PDB files but are not part of the protein. They must be removed before modeling.

- **Common pitfall:** Treating all PDB structures as equally reliable. A 3.5 Å structure with high B-factors should not be weighted equally with a 1.5 Å structure.

- **Common pitfall:** Ignoring alternative conformations. Some residues are modeled in multiple positions (occupancy < 1.0), representing genuine flexibility or modeling ambiguity.

### 7. Project Connection

The X-ray crystallography and PDB concepts map directly to the 3D-SynTree codebase:

- **`ARTIFACT_RESNAMES` filter set** in `syntree/data/curation.py`: Strips GOL, PEG, EDO, DMSO, and other crystallization artifacts from PDB structures.

- **Resolution filtering** in `scripts/preprocess_multidataset.py`: Keeps only structures with resolution ≤ 2.5 Å for training and evaluation.

- **`standardize_pocket()`** in `syntree/data/curation.py`: Handles alternative conformations and missing coordinates during pocket standardization.
