# 04. Training Stability Gradient Clipping and Learning Rate Schedules

### 1. What It Is

**Gradient clipping** limits the maximum norm of gradients during backpropagation, preventing exploding gradients that destabilize training.

**Learning rate schedules** adjust the learning rate during training—typically starting high for rapid initial learning, then decaying for fine-tuning.

### 2. Why It Exists

GFlowNet training can be unstable because:

- **Flow matching loss involves products of probabilities**, which can produce very large or very small gradients
- **The reward landscape is sparse**, causing occasional huge gradients when a high-reward molecule is found
- **Backward policy training** can be unstable because it learns to reverse a changing forward policy

Without gradient clipping, a single bad batch can destroy learned weights. Without learning rate decay, the model never settles into a good solution.

### 3. How It Works

#### Gradient Clipping

Compute gradient norm:
$$g_{norm} = \sqrt{\sum_i g_i^2}$$

If g_norm > max_norm, rescale:
$$g_i \leftarrow g_i \cdot \frac{\text{max\_norm}}{g_{norm}}$$

Typical max_norm values: 1.0, 10.0, or 100.0 depending on model size.

#### Learning Rate Schedules

**Cosine annealing:**
$$\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})(1 + \cos(\frac{\pi t}{T}))$$

Where t is current step, T is total steps, η_max is initial learning rate, η_min is final learning rate.

**Warmup + decay:**
- Linear warmup for first W steps (learning rate increases from 0 to η_max)
- Cosine decay for remaining steps

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Gradient norm | L2 norm of all gradients |
| Max norm | Clipping threshold |
| Learning rate | Step size for parameter updates |
| Cosine annealing | Smoothly decreasing learning rate |
| Warmup | Gradual learning rate increase at start |
| Learning rate decay | Reduction over training |
| Exploding gradients | Gradients with extremely large magnitude |
| Vanishing gradients | Gradients with extremely small magnitude |

### 5. What You Must Understand

- **Gradient clipping doesn't bias gradients.** It scales all gradients by the same factor, preserving direction while limiting magnitude.

- **Learning rate schedules are essential.** A fixed learning rate either converges too slowly (if small) or oscillates/diverges (if large).

- **Warmup helps early training.** Starting with a small learning rate prevents large updates before the model has learned anything useful.

- **Common pitfall:** Clipping too aggressively (max_norm = 0.1). This prevents learning by severely limiting gradient magnitude.

- **Common pitfall:** No warmup with high initial learning rate. Early training instability can permanently damage weights.
