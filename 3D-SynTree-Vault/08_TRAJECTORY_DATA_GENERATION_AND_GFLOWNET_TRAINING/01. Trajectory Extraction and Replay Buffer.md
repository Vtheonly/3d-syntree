# 01. Trajectory Extraction and Replay Buffer

### 1. What It Is

A **trajectory** in 3D-SynTree is a complete record of how a molecule was built step by step: which attachment atom was chosen, which synthon was selected, which reaction was applied, and what torsion angles were set at each step. **Trajectory extraction** is the process of recording these decisions during generative rollout so they can be used for training.

A **replay buffer** stores these trajectories (or individual transitions) for later sampling during training, breaking the correlation between consecutive samples and improving learning stability.

### 2. Why It Exists

GFlowNet training needs complete trajectories to compute flow matching losses. Each trajectory contains:

- **States:** The partially built molecule at each step
- **Actions:** Attachment atom, synthon, reaction, torsion choices
- **Rewards:** The terminal reward at the end
- **Log probabilities:** The policy's probability of each action

Without trajectory extraction, we couldn't compute the GFlowNet flow conservation loss, which requires knowing the full path from initial state to final molecule.

The replay buffer addresses the **non-stationarity problem**: as the policy improves, it generates better molecules. If we only train on the most recent trajectories, the model forgets earlier lessons. The replay buffer mixes old and new trajectories for stable learning.

### 3. How It Works

#### Trajectory Structure

Each trajectory contains:

| Field | Description |
|-------|-------------|
| Trajectory ID | Unique identifier |
| Initial core | Starting fragment SMILES |
| Step count | Number of synthesis steps (3-4 in 3D-SynTree) |
| Per-step state | Core SMILES, exposed handles, pocket context |
| Per-step action | Attachment atom, synthon ID, reaction family, torsion angle |
| Per-step log_prob | Policy log probability of each action |
| Terminal state | Final molecule SMILES and 3D coordinates |
| Terminal reward | Scalar reward from ThreeDReward |
| Flow | GFlowNet flow value at each state |

#### Replay Buffer Operation

1. **Store:** After each rollout, add the trajectory to the buffer
2. **Sample:** During training, sample a batch of trajectories uniformly
3. **Evict:** When buffer is full, remove oldest trajectories (FIFO)
4. **Prioritize (optional):** Sample higher-reward trajectories more frequently

#### Trajectory Validation

Every extracted trajectory must pass validation:
- **Canonical SMILES match:** The replayed molecule's canonical SMILES matches the observed SMILES
- **Physical validity:** Bond lengths, angles, and clashes within tolerance (PoseBusters)
- **Action consistency:** Each action was legal at the time it was taken

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Trajectory | Complete record of molecule construction |
| Step | Individual synthesis decision (attachment, synthon, reaction, torsion) |
| Replay buffer | Storage for trajectories sampled during training |
| Transition | (state, action, next_state, reward) tuple |
| Terminal reward | Final scalar reward for completed molecule |
| Flow | GFlowNet flow value at each state |
| Canonical SMILES | Standardized molecule identifier for validation |
| FIFO eviction | First-in-first-out buffer management |

### 5. What You Must Understand

- **Trajectories are the unit of GFlowNet training.** Unlike standard RL which trains on individual transitions, GFlowNet trains on complete trajectories with flow conservation constraints.

- **Replay buffers break temporal correlation.** Consecutive trajectories from the same policy are correlated (the policy changes slowly). Sampling uniformly from a buffer decorrelates samples.

- **Validation is essential.** Not every generated molecule is physically valid. Trajectories that produce invalid molecules (clashes, broken bonds) must be filtered before training.

- **Common pitfall:** Training only on recent trajectories. This causes catastrophic forgetting as the policy shifts.

- **Common pitfall:** Not validating trajectories. Invalid molecules in the training set teach the model to produce invalid chemistry.
