# 03. GFlowNet Flow Matching and Detailed Balance

### 1. What It Is

A **GFlowNet** (Generative Flow Network) is a generative model that learns to sample objects (molecules) proportional to a reward function R(x). Unlike standard RL which maximizes expected reward, GFlowNets learn a policy that covers all modes of the reward landscape.

The core principle is **flow conservation**: at each state, the total flow flowing in equals the total flow flowing out, except at terminal states where flow equals reward.

**Detailed balance** is a stronger condition: for each transition, forward flow equals backward flow.

### 2. Why It Exists

Standard maximum-likelihood or RL training tends to collapse to a single high-reward mode. GFlowNets avoid this by:

- **Sampling proportional to reward:** If molecule A has 10× the reward of molecule B, it's sampled 10× as often
- **Covering all modes:** Multiple distinct high-reward molecules are all represented
- **Diversity without explicit diversity rewards:** The flow matching objective naturally encourages coverage

This is critical for 3D-SynTree because we want to explore diverse chemical scaffolds, not just find one good molecule.

### 3. How It Works

#### Flow Definition

Each state s has a flow value F(s) ≥ 0 representing the total flow passing through s.

**Initial state:** F(s_0) = total flow (normalization constant)
**Terminal state:** F(s_T) = R(s_T) (flow equals reward)
**Intermediate states:** Flow is conserved

#### Detailed Balance Condition

For each transition s → s' via action a:

$$F(s) \cdot P_F(a | s) = F(s') \cdot P_B(s | s')$$

Where:
- P_F(a | s): Forward policy (probability of taking action a at state s)
- P_B(s | s'): Backward policy (probability of reversing to s from s')

#### Flow Matching Loss

The loss minimizes violation of detailed balance across all transitions:

$$\mathcal{L} = \sum_{(s,a,s')} \left( \log \frac{F(s) \cdot P_F(a | s)}{F(s') \cdot P_B(s | s')} \right)^2$$

In practice, this is computed on sampled trajectories using the log-ratio formulation for numerical stability.

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Flow F(s) | Total flow through state s |
| Forward policy P_F | Generates molecules step by step |
| Backward policy P_B | Decomposes molecules step by step |
| Detailed balance | Forward flow = backward flow per transition |
| Flow matching loss | Minimizes detailed balance violation |
| Terminal flow | F(s_T) = R(s_T) at terminal states |
| Reward-proportional sampling | Sample molecules proportional to reward |
| Mode coverage | Multiple high-reward modes all represented |

### 5. What You Must Understand

- **GFlowNets don't maximize reward.** They learn to sample proportional to reward. A molecule with reward 10 is sampled 10× more often than one with reward 1, but both are sampled.

- **The backward policy is essential.** Without P_B, there's no detailed balance condition and no flow matching loss.

- **Flow conservation is local.** It applies at each transition, not just globally. This is what makes GFlowNets tractable to train.

- **Terminal flow anchors the system.** F(s_T) = R(s_T) provides the boundary condition that propagates flow values backward through the trajectory.

- **Common pitfall:** Confusing GFlowNet with RL. RL maximizes expected reward; GFlowNet matches reward-proportional sampling.

- **Common pitfall:** Not training forward and backward policies jointly. They must be trained together because the loss couples them.
