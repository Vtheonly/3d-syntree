# 02. Policy Network Attachment Synthon Torsion Heads

### 1. What It Is

The **policy network** in 3D-SynTree consists of three specialized heads that make the sequential synthesis decisions:

1. **Attachment Head:** Selects which atom on the growing core to attach the next synthon to
2. **Synthon Head:** Selects which catalog synthon to add at the attachment site
3. **Torsion Head:** Predicts the dihedral angle for the newly formed bond

All three heads consume context from BipartitePaiNN (protein-ligand graph embeddings) and make decisions conditioned on the binding pocket environment.

### 2. Why It Exists

Each synthesis step requires three distinct decisions that cannot be made by a single output layer:

- **Attachment** is a per-atom classification problem (which core atom?)
- **Synthon selection** is a per-candidate ranking problem (which fragment from ~50 candidates?)
- **Torsion prediction** is a continuous regression problem (what dihedral angle?)

Separate heads allow each decision to use the appropriate output format and loss function while sharing the same BipartitePaiNN encoder.

### 3. How It Works

#### Attachment Head

For each pocket atom i:
1. Extract pocket node embedding h_i (scalar s_i + vector v_i)
2. Compute scalar score: α_i = MLP(s_i, ‖v_i‖)
3. Apply softmax over all atoms: p_i = exp(α_i) / Σ exp(α_j)
4. Sample attachment atom i ~ Categorical(p)

Output: Categorical distribution over core atoms

#### Synthon Head

For each catalog synthon candidate c:
1. Get synthon embedding e_c (256-dim projected pharm3D)
2. Compute context from BipartitePaiNN output at attachment site
3. Score: score_c = e_c · context (dot product)
4. Apply softmax: p_c = exp(score_c) / Σ exp(score)

Output: Categorical distribution over synthon candidates

#### Torsion Head

For the newly formed bond:
1. Extract local environment embedding around the bond
2. Predict von Mises parameters: mean direction μ and concentration κ
3. Sample dihedral angle θ ~ VonMises(μ, κ)

Output: Continuous angle in [-180°, 180°]

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Attachment head | Per-atom attachment probability |
| Synthon head | Per-candidate synthon probability |
| Torsion head | Continuous dihedral angle distribution |
| Softmax | Normalizes scores to probabilities |
| Dot-product attention | Context · embedding scoring |
| von Mises distribution | Circular distribution for angles |
| Categorical distribution | Discrete probability distribution |
| BipartitePaiNN context | Protein-ligand graph embeddings |

### 5. What You Must Understand

- **The attachment head is pocket-conditioned.** The probability of attaching at each atom depends on the local pocket environment, not just the core structure.

- **The synthon head uses dot-product attention.** This is efficient: score each candidate independently against the context, then softmax. The catalog embedding table acts as a key-value memory.

- **The torsion head predicts a distribution, not a point.** Von Mises(μ, κ) captures uncertainty: low κ = uniform (any angle OK), high κ = peaked (specific angle required).

- **All heads share the same encoder.** BipartitePaiNN processes the pocket-ligand graph once; all three heads read from its output.

- **Common pitfall:** Using the same head for attachment and synthon selection. They have different output spaces (core atoms vs catalog synthons) and different loss functions.

- **Common pitfall:** Treating torsion as a regression problem with MSE loss. Angles are circular; MSE treats 179° and -179° as far apart when they're actually 2° apart. Von Mises handles this correctly.

### 7. Project Connection

The policy head concepts map directly to the 3D-SynTree codebase:

- **`AttachmentHead`** in `syntree/models/policy.py`: Per-atom attachment probability from pocket node embeddings.

- **`SynthonHead`** in `syntree/models/synthon_head.py`: Dot-product attention over catalog synthon embeddings.

- **`ContinuousTorsionHead`** in `syntree/models/torsion_head.py`: Von Mises distribution for dihedral angle prediction.

- **`PolicyNetwork`** in `syntree/models/policy.py`: Combines all three heads with BipartitePaiNN encoder.

### 8. Required Depth

**Essential.** The policy heads are the decision-making component of 3D-SynTree—understanding them is essential for understanding how the model generates molecules.
