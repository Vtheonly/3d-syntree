# 05. Structure-Based vs Ligand-Based Drug Design

### 1. What It Is

**Structure-based drug design (SBDD)** uses the explicit 3D atomic structure of a target protein's binding pocket to guide molecule design. The model sees the protein's amino acid arrangement, pocket shape, electrostatics, and hotspots, and designs ligands that complement these features.

**Ligand-based drug design (LBDD)** operates using only known active and inactive small-molecule binders, without requiring the protein structure. It infers binding requirements from ligand similarities and differences.

| Aspect | SBDD | LBDD |
|--------|------|------|
| Required input | 3D protein structure | Known active/inactive ligands |
| Key advantage | Can design for novel targets | Works when structure unknown |
| Optimization target | Shape + electrostatic complementarity | Ligand similarity to actives |
| Example methods | Docking, 3D-SynTree, Pocket2Mol | QSAR, pharmacophore modeling, similarity search |

### 2. Why It Exists

Not all drug targets have experimentally determined 3D structures. For targets where the structure is unknown, LBDD is the only option. However, when the structure is available, SBDD offers significant advantages:

- **De novo design:** Can create molecules with novel scaffolds not seen in known actives
- **Atomic-level optimization:** Can tune specific interactions (e.g., adding a hydrogen bond to a specific residue)
- **Structure-guided lead optimization:** Can modify existing leads based on structural insights

3D-SynTree is an **SBDD model**. It requires 3D protein crystal coordinates as input to condition synthon selection and torsion prediction.

### 3. How It Works

#### SBDD Pipeline

1. **Obtain protein structure:** X-ray crystallography or Cryo-EM structure of the target with or without a bound ligand

2. **Extract binding pocket:** Define the binding site (typically 10 Å around a known ligand or predicted site)

3. **Prepare the protein:** Assign hydrogens, charges (pH 7.4), remove artifacts, optimize side chains

4. **Design/generate ligands:** Use docking, fragment growing, or generative models to create molecules that fit the pocket

5. **Score and rank:** Evaluate binding affinity using scoring functions or ML models

6. **Iterate:** Synthesize top candidates, test experimentally, refine design

#### 3D-SynTree's SBDD Approach

3D-SynTree conditions all decisions on the protein environment:
- **Pocket featurization:** Atomic positions, elements, and charges are encoded as a 3D point cloud
- **Cross-attention:** The attachment handle queries the local pocket environment via cross-attention
- **Structure-conditioned synthesis:** Reaction and synthon selection depend on pocket chemistry
- **Structure-conditioned torsion:** Dihedral prediction depends on local steric and electrostatic context

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Protein binding site | 3D region where ligand binds |
| Coordinate frame | Reference system for 3D positions |
| Lock-and-key complementarity | Shape matching between ligand and pocket |
| Induced fit | Mutual conformational adaptation |
| Pocket featurization | Encoding protein atoms for ML input |
| Cross-attention | Mechanism focusing on local pocket environment |
| De novo design | Creating novel molecules from scratch |
| Lead optimization | Improving existing molecules |

### 5. What You Must Understand

- **SBDD requires a structure.** Without an experimental structure (or a high-quality homology model), SBDD cannot be applied. LBDD is the fallback.

- **The quality of the structure matters.** A 1.5 Å structure enables precise atomic-level design; a 3.5 Å structure supports only rough shape-based design.

- **Induced fit is real but hard to model.** Proteins can rearrange side chains and even backbone to accommodate ligands. Most SBDD methods treat the protein as rigid or semi-flexible.

- **Common pitfall:** Designing against a single static structure when the target is conformationally dynamic. Some targets (e.g., GPCRs) have multiple active and inactive states.

- **Common pitfall:** Ignoring water molecules in the pocket. Ordered water can mediate key interactions or be displaced by ligand groups.

### 7. Project Connection

The SBDD vs LBDD concepts map directly to the 3D-SynTree codebase:

- **`MolecularFeaturizer.featurize_pocket()`** in `syntree/data/featurizer.py`: Encodes pocket PDB files into the 3D point cloud representation used by the model.

- **`BipartitePaiNN`** in `syntree/models/bipartite.py`: Processes the protein-ligand joint graph, with all decisions conditioned on pocket context.

- **Cross-attention** (`syntree/models/policy.py`): The attachment-handle query attends over pocket context generated by BipartitePaiNN.

- **Comparison targets:** 3D-SynTree is benchmarked against other SBDD methods (TargetDiff, DiffSBDD, Pocket2Mol) and 2D methods (SyntheMol, SynNet) in `scripts/run_comparative_benchmark.py`.
