# 06. Enamine REAL Space and Catalogs

### 1. What It Is

**Enamine REAL** is the world's largest commercially certified virtual chemical space, containing more than 38 billion compounds. Unlike traditional chemical catalogs that list individual compounds in stock, Enamine REAL is a *combinatorial* space: it enumerates all compounds that can be synthesized from Enamine's curated inventory of building blocks using validated, high-yield synthesis protocols.

Every compound in Enamine REAL is **make-on-demand**: Enamine guarantees synthesis with >80% success in 3–4 weeks. This bridges the gap between computer-generated designs and physical laboratory availability.

3D-SynTree does not use all 38 billion compounds. It uses a curated subset of approximately 50,000 synthons—building blocks with defined reactive handles—filtered for drug-like properties and stored in `enamine_real_50k_pharm3d_d256.h5`.

### 2. Why It Exists

The fundamental problem in generative drug discovery is the gap between virtual and real:

- **Virtual space:** ~10⁶⁰ possible drug-like molecules (essentially infinite)
- **Synthesizable space:** A tiny fraction that can actually be made in a lab
- **Purchasable space:** An even smaller fraction available from vendors today

Most generative models design molecules in virtual space with no regard for synthesizability. The result is beautiful docking scores and terrible reality. Enamine REAL exists to close this gap: any compound constructed within its grammar can be synthesized.

For 3D-SynTree, Enamine REAL is not just a vendor catalog—it is the **action space**. The model's discrete synthon selection chooses from 50,000 pre-validated fragments. Every generated molecule is, by construction, assembled from purchasable building blocks via certified reactions.

### 3. How It Works

#### Curation Pipeline

1. **Building block inventory:** Enamine maintains physical stocks of thousands of building blocks with defined reactive handles
2. **Reaction rules:** Certified medicinal chemistry reactions define how building blocks can be combined
3. **Virtual enumeration:** All combinations that pass the reaction rules are enumerated as the REAL space
4. **Filtering:** 3D-SynTree applies additional filters (Fsp³ ≥ 0.42, molecular weight, QED, handle availability)
5. **Embedding:** Each surviving synthon gets a 256-dim pharm3D descriptor vector
6. **Storage:** The curated library is saved as `enamine_real_50k_pharm3d_d256.h5`

#### The 50,000-Synthon Subset

3D-SynTree's catalog is not the full 38-billion-compound REAL space. It is a curated 50,000-entry subset optimized for:
- **Synthetic diversity:** Covering diverse scaffolds and handle types
- **3D character:** Fsp³ ≥ 0.42 to avoid flat grease
- **Drug-likeness:** QED and Lipinski-compatible properties
- **Computational tractability:** Small enough for fast lookup and embedding

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Enamine REAL | >38 billion virtual compounds, make-on-demand |
| Building block | Physical reagent in Enamine's inventory |
| Combinatorial enumeration | Virtual combination of building blocks via reactions |
| Synthon | Theoretical fragment incorporated into product |
| Curation filter | Criteria selecting 50k from 38B |
| pharm3d descriptor | 2138-dim feature vector per synthon |
| HDF5 storage | `enamine_real_50k_pharm3d_d256.h5` file format |
| SynthonCatalog | Python class managing the library |

### 5. What You Must Understand

- **Catalog size is a design choice, not a limitation.** 50,000 synthons is large enough for chemical diversity but small enough for the model to learn embeddings and for the inverted index to provide fast retrieval.

- **Every synthon is purchasable.** Unlike virtual compounds generated by diffusion models, every synthon in 3D-SynTree's catalog corresponds to a real chemical that can be ordered and synthesized.

- **The 80% success rate is Enamine's guarantee.** This means 80% of REAL-space compounds can be synthesized by Enamine in 3–4 weeks. 3D-SynTree inherits this guarantee by construction.

- **Common pitfall:** Confusing Enamine REAL (virtual, 38B) with Enamine Building Blocks (physical stock). REAL includes compounds made by combining stock building blocks; not all are physically in inventory.

- **Common pitfall:** Assuming the 50k catalog is static. The catalog can be regenerated with different filters (Fsp³ threshold, handle types, property cutoffs) as the project evolves.

### 7. Project Connection

The Enamine REAL concepts map directly to the 3D-SynTree codebase:

- **`scripts/build_synthon_catalog.py`**: Curates the Enamine REAL space into `enamine_real_50k_pharm3d_d256.h5`, applying Fsp³ filtering and pharm3D descriptor computation.

- **`SynthonCatalog`** in `syntree/chemistry/catalog.py`: Manages the 50,000-entry library. Each entry stores SMILES, handle types, Fsp³, molecular weight, and the 256-dim pharm3D embedding.

- **`enamine_real_50k_pharm3d_d256.h5`**: The HDF5 file storing the curated catalog with pre-computed descriptors for fast loading.

- **Action space:** `SynthonCatalog` serves as the discrete action space for the policy's synthon-selection head (`syntree/models/synthon_head.py`).

### 8. Required Depth

**Essential.** The catalog defines the boundary of chemical space that 3D-SynTree can explore.
