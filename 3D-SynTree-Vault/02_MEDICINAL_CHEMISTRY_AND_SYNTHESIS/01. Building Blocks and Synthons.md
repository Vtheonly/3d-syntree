# 01. Building Blocks and Synthons

### 1. What It Is

A **building block** is an actual, purchasable chemical reagent—a real compound you can order from a chemical vendor (such as Enamine, Sigma-Aldrich, or eMolecules) and receive in a vial. Building blocks come with defined reactive handles (functional groups capable of forming bonds), known purity, and a catalog price.

A **synthon** is the theoretical, idealized structural fragment that is added to a growing molecule during a synthesis step. It represents the piece that remains after a building block loses its leaving group. For example, if 4-bromobenzoic acid is a building block, the 4-carboxyphenyl fragment (–C₆H₄–COOH) that gets incorporated into a product is a synthon.

The distinction matters: building blocks are physical objects in a catalog; synthons are conceptual fragments that appear in a molecule. Multiple building blocks can produce the same synthon, and one building block can produce different synthons depending on which handle reacts.

### 2. Why It Exists

Modern drug discovery does not build molecules atom by atom. That would be impossibly slow and expensive. Instead, medicinal chemists assemble molecules from pre-manufactured structural fragments—building blocks—using reliable, high-yield reactions. This approach, called **fragment-based assembly**, offers several advantages:

- **Speed:** A complex molecule can be assembled in 3–4 reaction steps rather than 20+
- **Cost:** Building blocks are mass-produced and inexpensive
- **Reliability:** Certified reactions have known yields and conditions
- **Availability:** If you use catalog building blocks, your molecule can actually be made

For 3D-SynTree, this philosophy is taken to the extreme: the model's **action space is discrete and finite**. It does not generate individual atoms or coordinates. It selects from a curated library of 50,000 pre-validated synthons from Enamine REAL. Every molecule the model produces is, by construction, synthesizable from purchasable materials.

### 3. How It Works

#### The Assembly Process

A synthesis step in 3D-SynTree proceeds as follows:

1. **Handle selection:** The policy identifies an exposed reactive handle on the growing ligand (e.g., a carboxylic acid on the core scaffold).
2. **Reaction family selection:** The policy chooses a compatible reaction (e.g., amide coupling requires a carboxylic acid + an amine).
3. **Synthon selection:** The policy selects a synthon from the catalog that carries a compatible handle (e.g., an amine-containing synthon).
4. **Reaction execution:** RDKit applies the SMARTS template, forming a new bond and ejecting the leaving group (e.g., –OH from the acid, –H from the amine).
5. **3D embedding:** The new fragment is embedded in 3D space, anchored to the existing scaffold via Kabsch alignment, and the junction dihedral is predicted.

#### Handle Types

| Handle Type | Role | Example |
|-------------|------|---------|
| Primary handle | First point of attachment on a core scaffold | Carboxylic acid on a benzene ring |
| Secondary handle | Additional handle for further growth | Amine on the same ring, meta to the acid |
| Leaving group | Fragment ejected during reaction | –OH from acid, Cl from sulfonyl chloride |
| Core scaffold | Starting fragment to which synthons attach | A bicyclic heteroaromatic system |
| Terminal cap | Final fragment that ends growth | A small group like methyl or fluorine |

### 4. What It Consists Of

| Component | Description |
|-----------|-------------|
| Building block | Purchasable chemical reagent with defined handles |
| Synthon | Theoretical fragment incorporated into product |
| Reactive handle | Functional group capable of bond formation |
| Leaving group | Fragment departing during reaction |
| Core scaffold | Starting fragment in an assembly |
| Terminal cap | End-group that terminates synthesis |
| Synthon catalog | Library of pre-validated fragments (50,000 in 3D-SynTree) |
| Action space | Discrete set of all possible synthon selections |

### 5. What You Must Understand

- **3D-SynTree never generates atoms.** Every transition adds an entire, chemically valid fragment. This is fundamentally different from diffusion models that place individual atoms in space, which can produce pentavalent carbons, impossible ring closures, and other chemical violations.

- **The catalog is the constraint.** By selecting only from Enamine REAL building blocks, the model guarantees forward synthetic validity. If a fragment is in the catalog, it can be bought. If the reaction is certified, it can be run. The combination guarantees the output can be synthesized.

- **Synthon selection is discrete.** The policy outputs an index from 0 to K−1 (where K is catalog size, ~50,000), not continuous coordinates. This makes the action space combinatorially large but chemically bounded.

- **Common pitfall:** Confusing a building block with a synthon. A building block may carry two handles (bifunctional), but only one reacts in a given step. The other remains available for future growth.

- **Common pitfall:** Assuming all catalog entries are equally useful. Some synthons are common and versatile; others are rare and specialized. The inverted index (see [[06_CHEMINFORMATICS_AND_ALGORITHMS/06_Hashed Inverted Indices for Synthon Retrieval]]) helps the model retrieve relevant candidates efficiently.

### 7. Project Connection

The building block and synthon concepts map directly to the 3D-SynTree codebase:

- **`SynthonCatalog`** in `syntree/chemistry/catalog.py`: Manages the 50,000-entry Enamine REAL library. Each entry stores SMILES, handle types, Fsp³, molecular weight, and pharm3D descriptors.

- **Action $B_t$** in the policy factorization $P(B_t \mid r_t, \mathcal{P}, \mathcal{M}_t)$: Selects a synthon index from 0 to K−1, where K is the catalog size. This is the synthon-selection head in `syntree/models/synthon_head.py`.

- **`scripts/build_synthon_catalog.py`**: Curates the Enamine REAL space into `enamine_real_50k_pharm3d_d256.h5`, filtering by Fsp³ ≥ 0.42 and computing pharm3D descriptors for each entry.

### 8. Required Depth

**Essential.** The discrete synthon action space is the defining feature of 3D-SynTree's approach to synthesizability.
